# Security

This repo contains instruction files and small standard-library Python scripts. It has no server and handles no credentials.

If you find a script that can be made to run code, write outside its input path, or leak a file through crafted input (for example a malicious JSON or CSV model), please report it privately through GitHub's "Report a vulnerability" button on the Security tab rather than a public issue. If that button is not available, open an issue that says only "security report, please contact me" and leave out the details.

Prompt-injection reports against the skill text are welcome as normal issues: use the "wrong answer" template.
